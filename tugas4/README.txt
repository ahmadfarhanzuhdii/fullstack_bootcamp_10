# Bootstrap Portfolio

Responsive portfolio inspired by the supplied reference image.

## Features
- Bootstrap 5 Grid
- Responsive layout
- Colorful gradients
- Hover effects
- Bootstrap Modal
- Bootstrap Carousel
- Responsive project cards
- Contact form + toast
- Download CV demo button
- Bootstrap Icons

## Run
Open `index.html` in a browser.

Internet access is required for the Bootstrap CDN, Bootstrap Icons and Google Fonts.
